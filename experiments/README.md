# 组员 3：PLC ST 代码生成正式实验

本目录整理组员 3 的四组正式实验结果，来源为正式实验提交包精简版 v1.1。后续框架改进试跑和 2026 年 11 月 2 日的排错重跑均未计入正式成绩。

## 实验结果

20 道公共题加 14 道自编题，每组 34 题，共 136 条最终结果。整题通过表示 CODESYS 编译成功且该题所有有效逐拍功能用例通过；测试使用仿真输入输出，不代表真实设备验收。

| 组别 | 模型 | 框架 | 整题通过 | 通过率 | 编译通过 |
| --- | --- | --- | ---: | ---: | ---: |
| E1 | deepseek-v4.1-flash | Aider 0.86.2 | 18/34 | 52.94% | 32/34 |
| E2 | gpt-6.1-sol | Aider 0.86.2 | 16/34 | 47.06% | 32/34 |
| E3 | deepseek-v4.1-flash | 原版自研框架 | 8/34 | 23.53% | 28/34 |
| E4 | gpt-6.1-sol | 原版自研框架 | 7/34 | 20.59% | 33/34 |

P01、P08、P13、P14、P17、P18、P19、S11 在判据修订后各补跑四组。最终矩阵用这 32 条记录替换首轮对应记录，其余 104 条沿用首轮；整套结果不能称为完全盲测。四组使用相同的最终题目和功能判据，但框架内部策略与预算不完全相同，结论仅适用于本次配置。

本目录的 `数据/` 和 `测试用例/` 是实验当时使用的输入快照。仓库根目录的 `data/` 与 `tests/cases/` 后来由其他组员更新，文件内容存在差异；请勿用现行版本覆盖本目录的快照或倒推本次通过率。

## 本地核对

在本目录运行 python 脚本/verify_package.py。脚本只读取本地文件，不调用 API；它检查每组 34 题、136 条证据、32 条补跑替换记录及四张图。需要重新生成统计表或图，可分别运行 python 脚本/finalize_results.py --final 与 python 脚本/render_charts.py；绘图需要 matplotlib。

重新运行模型生成、CODESYS 编译或功能测试，需要另行配置软件、工具路径与凭据。[配置快照](配置/member4.codesys.yaml)含原实验电脑的绝对路径，不能直接用于其他电脑。

## 结果边界

- E3 有 24/34 题以预算状态停止。原版自研框架把请求和响应的 UTF-8 字节长度当作本地累计 token 估算，可能让修复过早停止；不能据此推断修正后必然通过。
- 136 条形式化验证状态均为 skipped。LTL 文件是规约材料，不能称作已由 PLCModelChecker 验证。
- 实验没有向模型请求发送 seed；运行目录中的 42 只是本地标识。
- 本目录没有 API Key。需要检查底层编译或仿真日志时，应使用小组保存的完整版原始提交包。

## 成员5规范路径

为满足任务书的 run_id 目录规范和统一复算要求，成员5在保留上述成员3原始目录的同时增加：

- `runs/E1` 至 `runs/E4`：136 个最终 run 的规范副本。
- `archive/source_runs`：成员3两个原始批次。
- `per_task.csv`、`34_task_matrix.csv`、`summary.csv`：仓库统一统计文件。
- `configs/E1.yaml` 至 `E4.yaml`：四组冻结配置。

`reproduction/` 是仓库自带 ST 解释器的独立离线重放，`evidence_kind=independent_replay`，不冒充 CODESYS 原始 actual。132 个有 `final.st` 的 run 中完成 72 个；60 个受解释器未支持的 ST 方言限制；4 个 abandoned run 没有源码。

统一复算入口：

```bash
python tools/stats.py
python experiments/verify_package.py
python tools/reproduce_runs.py
```
