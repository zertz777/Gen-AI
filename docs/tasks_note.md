# 题集使用说明（tasks_note）

本文件是 D1.6 的交付物，写给后面三个人看：成员 2 按它写解析器，成员 3 按它统计实验，成员 4 按它写用例。它只讲「怎么用」，题目内容在 `data/tasks/*.yaml`，规约在 `data/specs/*.ltl`。

## 1　三条命令

```bash
# 1) 从官方题库重新导出一遍题面（幂等，已有文件会被覆盖）
python tools/import_bank.py

# 2) 校验题面与规约：字段、I/O、K 映射、来源表、LTL 语法
python tools/ltl_check.py && python tools/schema_check.py

# 3) 重新生成来源表、多样性矩阵与冻结哈希
python tools/gen_meta.py
```

三个脚本都是零第三方依赖（自带 `tools/yaml_io.py`），在干净机器上只要 Python 3.10+ 就能跑。

## 3　命名规则

| 对象 | 规则 | 例子 |
| --- | --- | --- |
| 题号 | `P` + 两位数字（公开题，与题库编号一致）、`S` + 两位数字（自编题）。全局唯一，一经冻结不再改 | P07、S03 |
| 题面文件 | `data/tasks/<题号>.yaml`，一题一份 | `data/tasks/P07.yaml` |
| 规约文件 | `data/specs/<题号>.ltl`，与题面同名 | `data/specs/P07.ltl` |
| 条款号 | `C` + 条款库编号（1—10）。同题内同类条款重复时加小写字母后缀 | C4、C7b |
| 约束号 | `K` + 顺序号，题内连续，从 K1 起 | K1、K3 |
| I/O 变量名 | 公开题一律沿用题库原名，不翻译、不改大小写；自编题用大驼峰 | `bottleSensor`、`Drill_Motor` |
| 用例文件 | `tests/cases/<题号>.csv`，一题一份，行号即用例序号 | `tests/cases/P03.csv` |

**为什么变量名不许改**：Agent 生成的 ST 代码与 I/O 表必须逐字对得上，改一个大小写就会让成员 4 的逐周期比对全部失效——这是全组最贵的一类错误。

## 5　下游怎么用

**成员 2（框架）**：解析器只需要认 12 个字段；`io_table` 的 `direction` 只有 IN/OUT/INOUT三种取值；`requirement` 是自由文本，不要试图解析它，把整段塞进提示词即可。生成代码时的变量声明必须直接用 `io_table` 里的 `name` 与 `data_type`。

**成员 3（实验与报告）**：统计口径按「题」而不是按「文件」；`difficulty` 与 `category` 可直接用来做分组对比（难度分层、类别分层），报告里这两张表就是现成的。

**成员 4（测试与验证）**：`constraints` 的 K 编号是你写用例的引索——每条 K 至少要有一条用例覆盖，用例里的 `spec_refs` 填 `C4、C7b` 这种条款号；`.ltl` 里的条款号可直接作为期望行为的判据。注意有 38 条 K 没有对应的 LTL 条款（见第 6 节），这些只能靠用例。

**成员 5（仓库与交付）**：`data/` 目录整包交给 A3；文件命名规则见第 3 节，冻结哈希在 `data/sha256sums.txt`。

## 6　已知口径与例外

1. **扫描周期统一 20 ms。** 规约里所有 `[a,b]` 区间单位是扫描周期：200 ms=10、500 ms=25、2 s=100、3 s=150、5 s=250、30 s=1500。
2. **P14 只写 2 条规约。** 纯组合逻辑（字符串进、整数出），没有状态可约束；语义正确性靠用例。理由写在 `data/specs/P14.ltl` 的 `# note:` 里，`schema_check` 认这条 note。
3. **P08 的数组元素用别名映射。** `channels[].enable` 等写不进一阶命题，用 `# alias: chEn := channels[].enable` 声明，逐通道结果由用例覆盖。
4. **部分约束只能由用例覆盖。** 例如「错误码写进 Status」「维护计时精度」，LTL 层无法精确表达；`schema_check` 把它们列为警告并列明题号，不阻断冻结。
5. **无急停信号的题不写 C1。** P11、P12、P13、S04 等题在文件头用 `# note:` 写明原因，而不是硬凑一条恒真条款——这是评审口径（见 `data/review.md` R6）。
6. **错误码分配。** 公开题沿用题库原错误码（16#8xxx）；自编题按题号顺序占用 16#81xx—16#8Bxx，不重号。

## 7　冻结与变更

- 冻结时刻：D3 10:00。冻结后只允许补缺失字段，不允许改需求、改变量名、改条款数。
- 冻结凭据：`data/sha256sums.txt`（68 个文件的 SHA-256）。
- 变更流程：改题 → 同时改 `data/CHANGELOG.md` → 重跑第 1 节三条命令 → 在群里通知成员 2、3、4（他们的产物要重跑）。
