# 成员3答辩问答（3条）

## Q1 为什么 Aider 组的严格整题通过数更高，能否说明 Aider 的算法更好？

只能说明在本作业的冻结题集、同机工具链和本次配置下，Aider 两组分别通过 18/34 和 16/34，原版自研两组分别通过 8/34 和 7/34。E3 有 24 题受预算终止影响，且预算实现存在 UTF-8 字节长度误当 token 的问题；Aider 与自研的内部上下文和修复策略也不同。因此这组数据支持“本版自研框架还有明显改进空间”，不足以给两个框架作普遍排名。

证据：`experiments/summary.csv`、`docs/report/ch4.md` §4.3-§4.5、`experiments/runs/E3/`。

## Q2 四个组的通过率怎样算，为什么不把超时算成失败？

整题通过要求权威编译通过且所有有效功能用例全部通过，分母始终是 34。超时、工具错误、缺失和预算终止单独列出，避免把基础设施故障算成模型写错。用例通过率只用实际进入测试阶段的题目，因此各组分母不同，不能代替 34 题统一分母的整题通过率。

证据：`experiments/per_task.csv`、`experiments/34_task_matrix.csv`、`tools/stats.py`。

## Q3 题面或用例仍有争议，实验结果还可信吗？

已提交的 136 条结果保留原始判定，可回指到 run、候选评估和最终 ST，因此“当时记录是什么”可核验。但争议题不能作为模型或框架优劣的决定性证据，尤其是 P19、S11、S05-06。若修订判据，应在四组相同条件下另建批次补测并保留旧记录，不能直接覆盖或重算成看似更高的结果。

证据：`docs/判据待核查.md`、`docs/统稿前审查说明.md`、`experiments/archive/source_runs/`。
