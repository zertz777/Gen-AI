# 组员 1 提交包：题集与形式化规约（A3 / D1.1—D1.8）

本包对应课程期末大作业的 **A3（题集与规范）**，同时覆盖任务书里组员 1 的八项交付物。
内容是一份**可判定的 PLC 编程题集**：34 道题（课程公开题 20 道 + 自编 14 道），每题 12 字段题面 + 带条款编号的 LTL 规约，配来源表、多样性矩阵、评审记录，以及九支零依赖脚本（其中四支用于校验与重建，见第 1、3 节）。

## 1　三分钟验证

包是自足的：只要 Python 3.10+，不需要 `pip install` 任何东西（`tools/yaml_io.py` 是自写的）。

```bash
# 1) 语法检查：34 份规约的 LTL 是否合法、命题能否溯源到本题 I/O
python tools/ltl_check.py

# 2) 数据检查：12 字段、I/O 方向类型、K 编号映射、来源表完整性
python tools/schema_check.py

# 3) 一致性检查：从官方题库重新导入一遍题面（幂等，应与包内一致）
python tools/import_bank.py --check

# 4) 重算来源表、多样性矩阵与冻结哈希
python tools/gen_meta.py
```

四条命令的预期输出：第 1 条打印「规约文件 34 份，条款合计 178 条 …… 全部通过」；第 2 条打印「schema_check 通过」，并附若干条「约束由用例覆盖」的警告（口径见 4.4）；第 3、4 条应无报错。

## 3　脚本各管什么

| 脚本 | 作用 | 是否会写盘 |
| --- | --- | --- |
| `tools/yaml_io.py` | 自写的 YAML 读写器（受控子集，零依赖） | 否 |
| `tools/curation_public.py` | 20 道公开题的人工校对字段（类别、初始状态、约束、错误示例） | 否 |
| `tools/curation_self.py` | 14 道自编题全文（需求、I/O、约束、错误示例、来源） | 否 |
| `tools/import_bank.py` | 把官方 JSON + 两个 curation 合成 `data/tasks/*.yaml` | 是（`--check` 只校验） |
| `tools/gen_specs.py` | 生成 34 份 `.ltl` 与 `PROPOSITIONS.md` | 是 |
| `tools/ltl_check.py` | LTL 递归下降解析与溯源检查 | 否 |
| `tools/schema_check.py` | 题面/规约/来源表的交叉一致性检查 | 否 |
| `tools/gen_meta.py` | 生成来源表、多样性矩阵、冻结哈希 | 是 |
| `tools/gen_docs.py` | 生成 `docs/tasks_note.md` 与 `docs/report/ch2.md` | 是 |

规约与文档都是**脚本产物**：改数据只改 curation 或 gen_specs，再重跑脚本，不手改 `.ltl` 与 `.md`——保证代码与文档同源，不会出现「文档说 178 条、文件里只有 176 条」。

## 4　数据口径（下游必须照这个口径读）

### 4.1　规模

| 统计项 | 数值 |
| --- | --- |
| 题目总数 | 34（公开 20 + 自编 14） |
| I/O 点合计 | 316 |
| 约束（K）合计 | 143 条 |
| LTL 条款合计 | 178 条（平均 5.2 条/题） |
| 难度分布 | 易 9、中 14、难 11 |
| 类别分布 | A 6、B 11、C 11、D 6 |

### 4.2　命名与编号

- 题号：`P01—P20` 公开题（与题库编号一致）、`S01—S14` 自编题；全局唯一，冻结后不改。
- 条款号：`C` + 条款库编号（1—10），同题内同类条款重复时加小写后缀（C2b、C7b）。
- 约束号：`K` + 顺序号，题内连续，从 K1 起。
- 变量名：公开题一律沿用题库原名，不翻译、不改大小写；自编题用大驼峰。

### 4.3　时间与错误码

- 扫描周期统一 **20 ms**，规约里 `[a,b]` 的单位是扫描周期：200 ms=10、500 ms=25、2 s=100、3 s=150、5 s=250、30 s=1500、60 s=3000。
- 错误码：公开题沿用题库原值（16#8xxx）；自编题按 `16#81xx—16#8Dxx` 顺序占用，不重号。

### 4.4　例外口径（写在数据里，不靠口头解释）

- **P14 只写 2 条规约**：纯组合逻辑（字符串进、整数出）没有状态可约束，文件头用 `# note:`
  写明理由，语义正确性由用例覆盖。
- **P08 用别名**：数组元素（`channels[].enable` 等）写不进一阶命题，用 `# alias: chEn := …`
  声明别名，逐通道语义交给用例。
- **35 条 K 只能由用例覆盖**：例如「错误码写进 Status」「维护计时精度」，LTL 表达不了；
  `schema_check` 把它们列为警告并逐题列名，不阻断冻结。
- **无急停信号的题不写 C1**：用 `# note:` 说明原因，不硬凑恒真条款。
