# 数据多样性矩阵（v2.0，2026-10-30）

本文件回答课程要求里的第三条：数据集是否有多样性。做法不是罗列题目，而是把 34 道题投影到六个正交维度上，给出每格的题号，然后明确指出哪些格是空的、为什么允许它空。

约定：`P01—P20` 为课程公开题，`S01—S14` 为自编题。所有计数由 `tools/gen_meta.py` 从 `data/tasks/*.yaml` 与 `data/specs/*.ltl` 现算，不接受手工填写。

## 3　程序结构

打标规则（可在 `tools/gen_meta.py` 的 `structures()` 里复核）：含 TIME/LTIME 类型记「带定时」；含 ARRAY 类型记「带数组」；类别为 C 或 I/O 名含 Status/State/Step/Segment/Mode/Recipe 记「带状态机」；I/O 名含 Volume/Count/Total/Sum/Average 或有 32 位整型记「带累计」；以上都没有记「纯组合」。一题可带多个标签。

## 6　原创度（自编题与来源题的关系）

## 7　空格与短板

1. **没有 STRING 输入题。** 题库的 P14 用字符串做 IPv4 解析，但 PLC 侧 ST 的字符串处理各家编译器支持不一，写进规约层没有可移植的判定方式，因此自编题不碰字符串。
2. **没有多任务/中断类题目。** 课程要求未涉及 OS 级任务调度，加了反而超出「PLC 代码自动生成」的评测范围。
3. **A 类没有难题、D 类只有 1 道难题。** 开关量联锁（A）一旦加上节拍、状态机或故障分级，就会自然落到 C/D 类；硬在 A 类里堆难题只会造出「伪难题」。这两个空格是设计选择，不是遗漏。
4. **模拟量题一律用 INT/REAL 工程量，不用裸 ADC 码。** 量程换算属于 I/O 配置，不属于控制逻辑，混进来会让规约与用例都变模糊。
5. **自编题上限 12 个 I/O 点。** 超过 12 点的题（如 P19 的 24 点）属于公开题，自编题不做这么大：点一多，逐周期用例的书写成本会按点数×周期数增长，三天窗口内写不完。
